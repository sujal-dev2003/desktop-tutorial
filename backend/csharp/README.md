# C# API starter

Use ASP.NET Core Minimal APIs if a hosted backend is needed. Keep the routes aligned with `backend/README.md`, use parameterized queries for SQLite, and return the same field names as the frontend data objects (`id`, `name`, `bio`, `detail`, and category fields).

This repository does not include a generated `.csproj` yet so the static GitHub Pages workflow remains unchanged. A future implementation can be created with:

```text
dotnet new webapi -n WizardingAtlas.Api
```
